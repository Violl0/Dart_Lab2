## Что изучили

- Создание классов и объектов в Dart
- Конструкторы: позиционные и именованные параметры (required)
- Переопределение методов (@override, toString)
- Геттеры
- Статические поля и приватность (нижнее подчёркивание)
- Подключение пакетов через pub.dev (ansicolor)

## Ответы на вопросы

1. В чём разница между полем класса и обычной переменной в функции?
   Поле в объекте переменная только в функции

2. Что такое конструктор и зачем он нужен?
   Метод для создания объекта

3. Зачем нужен @override перед toString()?
   Переопределяем метод родителя

4. Чем статическое поле static int _counter отличается от обычного поля?
   Одно на все объекты а обычное у каждого своё

5. Что означает нижнее подчёркивание в _counter?
   Приватное поле
